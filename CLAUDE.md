## Personal AI-usage knowledge base

This repo also doubles as the storage location for Lars's running collection of
actionable tips extracted from AI/Claude-related podcasts and videos. Entries are added via
the global `/youtubetranscribe` command (`~/.claude/commands/youtubetranscribe.md`), which
writes here and pushes regardless of which project directory it's run from. This file's
`@`-import also loads the knowledge globally (see `~/.claude/CLAUDE.md`), so this repo-local
import is redundant but kept for when you're working directly in this repo.
